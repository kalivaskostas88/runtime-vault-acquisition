# ACE media ingress research
Isolated research branch only. Main and all pre-existing production workflows are untouched.
Only public source URLs, bounded manifest and workflow code are stored here. No user Core, score, credentials, media binaries or perceptual claims are committed.
Artifacts are temporary sensor transport, configured for one day retention. No cookies, login, DRM bypass, proxies or player impersonation. A failed source is recorded, never treated as media evidence.
